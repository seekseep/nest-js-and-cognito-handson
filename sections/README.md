# 進め方

## 1 つのプロジェクトを育てる

このハンズオンでは、最初に作ったプロジェクトに節ごとに機能を足していきます。リポジトリの `sections/<章>/<節>/` には、**その節を終えた時点のプロジェクト** がそのまま入っています。

```text
sections/
├── 02-hello-world/
│   ├── 01-nextjs/       ← 02 章 01 節を終えた時点
│   └── 02-nestjs/       ← 02 章 02 節を終えた時点
├── 03-podman/
│   └── ...
```

手元では 1 つのフォルダ（たとえば `~/handson/my-app/`）を育てていきます。各節のページの手順どおりにファイルを足したり書き換えたりしてください。

## ページの読み方

### コードの差分

ファイルを書き換える手順は、前の節との差分で示します。行頭が `+` の行を足し、`-` の行を消します。新しく作るファイルは、すべての行に `+` が付きます。

```diff lang="ts"
 async function bootstrap() {
   const app = await NestFactory.create(AppModule);
-  await app.listen(process.env.PORT ?? 3000);
+  await app.listen(process.env.PORT ?? 3001);
 }
```

左の行番号は「書き換える前の行」、右の行番号は「書き換えた後の行」です。

### この節を終えたときのディレクトリ

ページの最後に、その節を終えたときのディレクトリを載せています。前の節から **追加したファイル** と **変更したファイル** には印が付いています。手元のディレクトリと見比べてください。

その下のボタンから、その節を終えた状態のプロジェクトを ZIP でダウンロードできます。

- 途中の節から始めたいときは、ひとつ前の節の ZIP をダウンロードして展開してください
- 展開したら、`frontend/` と `bff/` でそれぞれ `npm install` を実行します（`node_modules/` は ZIP に入っていません）
- `.env` / `.env.local` は ZIP に入っていません。`.env.example` をコピーして作ってください（05 章から）

## 前提

- macOS / Windows（WSL2）/ Linux のどれか
- ターミナルの基本的な操作（`cd`・`ls`）ができる
- JavaScript を書いたことがある。TypeScript は書きながら覚えれば大丈夫です
- 05 章から AWS アカウントを使います（Cognito のユーザープールは無料枠の範囲で作れます）

## 使うもの

| 道具 | 役割 | 入れる節 |
|---|---|---|
| Node.js 26（LTS） | Next.js と NestJS を動かす | 01 章 |
| Podman 6 | コンテナで開発環境を動かす | 01 章・03 章 |
| VS Code | エディタ。OpenAPI の拡張機能も使う | [開発ツール](./TOOLS.md) |
