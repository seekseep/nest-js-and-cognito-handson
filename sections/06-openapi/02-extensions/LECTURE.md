# VS Code 拡張機能と lint

![06 章 VS Code 拡張機能と lint](./images/00-thumbnail.svg)

`openapi.yaml` は、字下げや `$ref` の書き間違いに気づきにくいファイルです。この節では、VS Code の拡張機能を入れ、決まりどおりに書けているかをコマンド（**Redocly CLI** の lint）でも確かめられるようにします。

## 使う拡張機能

| 拡張機能 | ID | できること |
|---|---|---|
| OpenAPI (Swagger) Editor | `42Crunch.vscode-openapi` | 入力の補完、OpenAPI explorer（パスや部品の一覧）、`$ref` の参照先へ移動、Swagger UI / ReDoc でのプレビュー |
| Redocly OpenAPI | `Redocly.openapi-vs-code` | `redocly.yaml` の決まりで間違いを表示、参照先ののぞき見 |
| YAML | `redhat.vscode-yaml` | YAML の字下げや書き方の間違いを表示 |

VS Code の拡張機能のビューで ID を検索して、3 つとも入れます。

:::warning
VS Code では `api/` を開いてください（`handson/` や `api/src/` ではなく）。後で作る `redocly.yaml` は、開いたフォルダの直下にあるときに読まれます。
:::

## 拡張機能を使ってみる

`openapi.yaml` を開き、`'#/components/schemas/Note'` を `'#/components/schemas/Notes'` に変えてみると、参照先が無いことが赤い波線で示されます（確かめたら元に戻します）。エディタの右上のプレビューのボタンを押すと、API のドキュメントの画面が横に出ます。

## Redocly CLI を入れる

コマンドでも確かめられるようにします。

```bash
npm install -D @redocly/cli
```

`package.json` の `scripts` に、`openapi.yaml` を確かめるコマンドを足します。

::diff{file="api/package.json"}

まだ `redocly.yaml` を作らずに、実行してみます。

```bash
npm run lint:api
```

```text
validating openapi.yaml...
[1] openapi.yaml:14:5 at #/paths/~1notes/get

Every operation should have security defined on it or on the root level.
...
Error was generated by the security-defined rule.
...

❌ Validation failed with 5 errors and 3 warnings.
```

Redocly は、OpenAPI として正しいかに加えて、**書き方の決まり（ルール）** でも確かめます。問題ごとに、場所（`openapi.yaml:14:5`）と、どの決まり（`security-defined` など）で見つかったかが出ます。何も設定しないと、おすすめの決まり（`recommended`）がすべて使われます。

## 決まりを redocly.yaml に書く

どの決まりを使うかを `redocly.yaml` に書きます。拡張機能も CLI も、このファイルを読みます。

::diff{file="api/redocly.yaml"}

- `extends: [recommended]` … Redocly のおすすめの決まりを使います
- `rules` … このプロジェクトに合わない決まりを切ります

| 決まり | 指摘する内容 | 切る理由 |
|---|---|---|
| `security-defined` | 操作に認証（`security`）が無い | この API には認証を付けない |
| `info-license` | `info` にライセンスが無い | 公開しない API |
| `no-server-example.com` | `servers` が `localhost` | 手元で動かす API |
| `operation-4xx-response` | `4xx` の応答が無い | 一覧（`GET /notes`）は `4xx` を返さない |

もう一度実行します。

```bash
npm run lint:api
```

```text
validating openapi.yaml...
openapi.yaml: validated in 10ms

Woohoo! Your API description is valid. 🎉
```

:::faq

### 推奨の拡張機能の表示が出てこない

`api/` ではなく、その上のフォルダや `api/src/` を開いていないか確かめてください。表示を一度閉じた場合は、拡張機能のビューで `@recommended` と検索すると出てきます。

### Redocly の拡張機能が間違いを表示しない

`redocly.yaml` が、VS Code で開いたフォルダの直下にあるか確かめてください。

:::
