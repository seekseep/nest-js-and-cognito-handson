# 開発ツール（VS Code / ブラウザ）

入れ方は [Node.js と VS Code を入れる](./01-setup/01-nodejs/LECTURE.md) の節にあります。

## VS Code

育てているプロジェクトのフォルダ（`api/`）で `code .` を実行して開きます。06 章の `redocly.yaml` は、開いたフォルダの直下にあるときに読まれるので、`api/` を開いてください。

`` Ctrl + ` ``（バッククォート）でエディタの中にターミナルが開きます。API を動かしたまま curl で呼ぶときは、ターミナルを 2 つ開いて（右上の **＋**）使い分けます。

## ブラウザの開発者ツール

05 章で画面がうまく動かないときは、ブラウザの開発者ツール（`F12`）の **Console** タブでエラーを、**Network** タブで API へのリクエストと応答を確かめます。
